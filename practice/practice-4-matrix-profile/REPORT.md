Матричный профиль содержит расстояние от каждого окна до ближайшего подходящего соседа. Расстояния вычисляются после нормализации окон. Для одного ряда учитывается заданная зона исключения; для разных рядов выполняется поиск между всеми допустимыми окнами. Временная настройка зоны STUMPY восстанавливается после каждого вызова, в том числе при ошибке.

Первая пара разделена двумя неделями, четвёртая — одной неделей. Небольшие нормализованные расстояния показывают сходство формы потребления, не равенство абсолютного уровня нагрузки. Вывод о конкретной причине сезонности по этим данным не делается.

В Telegram ошибочно передавалась зона исключения вместо длины окна. Там профиль был рассчитан для **83**, а не 165 отсчётов; старые расстояния 0.72–0.76 относятся к другому эксперименту. Здесь диапазон расстояний найденных мотивов — **1.226625–1.375152**.

- Accuracy: **94.6679%**.

Значение профиля ниже порога обозначает лестницу. Истинные метки подъёма и спуска (1 и 2) объединены; ходьба (0) остаётся вторым классом. Сравнение выполняется по метке в центре каждого окна. График показывает выделение основных участков лестницы с ошибками у переходов и отдельных выбросов профиля.
