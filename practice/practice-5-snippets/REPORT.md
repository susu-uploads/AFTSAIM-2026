## Данные и параметры

За основу взята первая задача Telegram; дополнены голосование трёх осей и подбор числа сниппетов. Сохранены демонстрационный ряд из синусоиды и пилообразного сигнала, зависимости курса и исходный шаблон задания.

Файл PAMAP имеет форму **20 × 146000**: признаки записаны по строкам. Временные метки находятся в строке 0, активности — в строке 1, гироскоп X/Y/Z — в строках 10–12. Поэтому исходная индексация Telegram корректна.

Применён фильтр **1790 ≤ t ≤ 1930**. Доступны **13430** отсчётов от **1795.71** до **1930.00 с**; данных с 1790 до 1795.71 в выбранном файле нет. В интервале присутствуют активности 12 (подъём) и 13 (спуск по лестнице). Пропусков в трёх осях гироскопа нет.

Фиксированные параметры: **m=600**, **percentage=0.5**, для разметки **k=2**. При частоте 100 Гц сниппет имеет длительность 6 секунд. Параметры не подбирались по accuracy.

## 1. Одномерная разметка Y

Сниппеты начинаются в позициях **6000** и **10800** от начала выбранного фрагмента. Доли представляемых окон — **57.8443%** и **42.1557%**.

Разметка STUMPY относится к **n−m+1 = 12831** положениям окон. Для оценки каждое положение сопоставлено с истинной меткой в центре окна. Края (300 точек слева и 299 справа) не дополнены нулевым классом. Номера сниппетов произвольны: их перестановка для метрики выбирается по максимальному совпадению с активностями.

Accuracy Y: **90.1644%**.

Сохранённые в Telegram 86.35% воспроизводятся его методикой: сравнение по началу окна с заполнением остатка ряда нулевым классом. Здесь применяется согласованная оценка по центрам окон, поэтому числа относятся к разным способам оценки. Сами найденные сниппеты не подгонялись под старую точность.

## 2. Три оси и большинство голосов

На X и Z выполнен такой же поиск, как на Y. Номера кластеров X и Z согласованы с Y по максимуму взаимного совпадения; истинные метки на этом этапе не используются. При равенстве совпадений сохраняется исходная нумерация. Затем для каждого центра окна берётся большинство трёх бинарных голосов.

| Метод | Accuracy |
|---|---:|
| X | 91.0529% |
| Y | 90.1644% |
| Z | 88.8395% |
| Большинство | 93.4378% |

Все четыре оценки получены на одинаковых 12831 окнах. Большинство улучшило разметку относительно Y на **3.27 процентного пункта**. Ошибки разных осей частично компенсируются. Это оценка кластерной разметки данного фрагмента, а не качество на независимой тестовой выборке.

## 3. Выбор числа сниппетов

Для каждой оси выполнен один поиск с **k=9**. Возвращённые STUMPY площади соответствуют накопленному покрытию после добавления каждого сниппета. Общая ProfileArea — среднее площадей трёх осей. Формула:

`Change[k] = ProfileArea[k−1] / ProfileArea[k] − 1`.

Для k=1 мера не определена. Сравниваются значения k=2…9, выбор делается по максимальному пику Change, без истинных меток и accuracy.

| k | Средняя ProfileArea | Change |
|---:|---:|---:|
| 1 | 161070.924161 | — |
| 2 | 139223.412515 | 0.156924 |
| 3 | 126306.448594 | 0.102267 |
| 4 | 117643.701620 | 0.073635 |
| 5 | 109427.238178 | 0.075086 |
| 6 | 101712.854956 | 0.075845 |
| 7 | 94174.046524 | 0.080052 |
| 8 | 87268.441453 | 0.079131 |
| 9 | 80544.306686 | 0.083484 |

Выбрано **k=2**. Добавление второго сниппета даёт наибольшее относительное улучшение. Дальнейшее снижение площади само по себе не означает, что нужно увеличивать число сниппетов до девяти.
